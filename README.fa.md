## 📖 معرفی پروژه

این نرم‌افزار یک برنامه وب مستقل و محلی (Local-First) است که برای معامله‌گران فعال نوبیتکس طراحی شده است. این سیستم تاریخچه معاملات و سفارش‌های خام شما را به ابزاری قدرتمند برای تصمیم‌گیری تبدیل می‌کند: از چارت تکنیکال پیشرفته تردینگ‌ویو و تقویم سود و زیان روزانه گرفته تا رادار سنجش خطر لیکوییدیشن، ریز محاسبات بهای تمام‌شده دارایی‌ها، ماشین‌حساب سایز پوزیشن و ژورنال‌نویسی هوشمند معاملات.

**طراحی بر پایه اولویت حریم خصوصی (Offline-First):**
تمامی اطلاعات معاملات، یادداشت‌های استراتژی و کلیدهای API شما فقط و فقط روی سیستم شخصی خودتان نگهداری شده و هرگز به هیچ سرور خارجی یا واسط ارسال نمی‌شود.

## 🌟 ویژگی‌های کلیدی

### ۱. 📊 ارزش‌گذاری دارایی‌ها و سود واقعی خالص (True Net PnL)
- **محاسبه سود واقعی خالص:** تمام ارقام سود و زیان پس از کسر تمامی کارمزدهای خرید و فروش اسپات، کارمزد باز کردن و بستن پوزیشن تعهدی، کارمزدهای تمدید روزانه و **سهم استخر مشارکت نوبیتکس** محاسبه می‌شوند.
- **محاسبه ارزش کل پورتفولیو در لحظه:** تجمیع موجودی دارایی‌های اسپات و ودیعه‌های درگیر در پوزیشن‌های تعهدی با آخرین قیمت‌های بازار نوبیتکس.
- **پشتیبانی دوگانه ارزی:** نمایش همزمان ارزش‌ها به تتر (USDT) و تومان ایران (IRT).
- **پنجره اختصاصی جزئیات دارایی (Asset Details Modal):** کلیک روی هر رمزارز در تب اسپات، پاپ‌آپ تحلیلی جامعی شامل میانگین بهای تمام شده (WAC)، حجم خرید/فروش، سود تحقق‌یافته و شناور، سفارشات باز فعال همان ارز و دفترکل ۷ ستونه سابقه معاملات را نمایش می‌دهد.

### ۲. 📉 موتور چارت پیشرفته TradingView (کاملاً آفلاین)
- **تحلیل تکنیکال حرفه‌ای:** مجهز به نسخه کامل کتابخانه پیشرفته **TradingView Advanced Charting Library (نسخه ۲۸)** مستقر در پروژه بدون وابستگی ابری، همراه با ۱۰۰+ اندیکاتور، ابزارهای خطوط روند و فیبوناچی.
- **تایم‌فریم‌های چندگانه:** پشتیبانی روان از رزولوشن‌های `15m`, `30m`, `1h`, `4h`, `1D`, `1W` با تجمیع و کش سروری کندل‌ها.
- **هماهنگی کامل با آدرس صفحه (URL Sync):** نماد و تایم‌فریم چارت مستقیماً با پارامترهای آدرس (`?tab=chart&symbol=USOONUSDT&tf=1D`) هماهنگ هستند.
- **محور زمان دوگانه:** نمایش تاریخ‌های تقویم **جلالی (شمسی)** روی محور زمان چارت در حالت فارسی و **میلادی** در حالت انگلیسی.

### ۳. 📅 تقویم سود و زیان روزانه (PnL Calendar)
- **شبکه ماهانه تعاملی:** سلول‌های روزانه دارای رنگ‌بندی تفکیک‌شده (سبز برای روزهای سودده، قرمز برای روزهای زیان‌ده، خاکستری برای روزهای بدون معامله).
- **ادغام فیوچرز تومانی و تتری:** احتساب تمامی پوزیشن‌های بسته‌شده تتری و تومانی تعهدی در دسته‌بندی روزهای تقویم.
- **سیستم دوگانه تقویم (Dual Calendar):** هماهنگی کامل تقویم **شمسی (جلالی)** در حالت فارسی و **میلادی** در حالت انگلیسی.
- **بررسی روز (Day Inspector):** امکان کلیک روی هر روز تقویم برای مشاهده ریز معاملات اسپات و پوزیشن‌های تعهدی بسته‌شده در آن تاریخ.

### ۴. 📈 نمودار رشد سرمایه و سود تجمعی (Equity Curve)
- **ایزولاسیون ۱۰۰٪ معاملات اسپات:** محاسبه خالص عملکرد و ارزش دارایی‌های اسپات بدون دخالت ضرایب اهرمی فیوچرز و بدون انحراف ناشی از برداشت‌های ریالی بانکی.
- **تایم‌لاین تاریخی پیوسته:** نمایش مسیر رشد واقعی دارایی و سود تجمعی از تاریخ اولین معامله اسپات تا کنون.
- **شاخص مقایسه‌ای بیت‌کوین (BTC Benchmark):** رسم همزمان خط بازدهی بیت‌کوین روی نمودار برای مقایسه میزان آلفا و برتری بازدهی شما نسبت به کل بازار.
- **فیلتر بازه زمانی منعطف:** نوار فیلتر با گزینه‌های سریع کل دوره (`All Time`)، ۳۰ روزه (`30D`)، ۹۰ روزه (`90D`)، از ابتدای سال (`YTD`) و انتخاب تاریخ دلخواه (`Custom`) با ذخیره در URL.

### ۵. ⚡ رادار هشدار فاصله تا لیکوییدیشن (Liquidation Radar)
- **پایش زنده حاشیه امن:** محاسبه بلادرنگ درصد فاصله قیمت لحظه‌ای تا قیمت لیکویید برای تمامی پوزیشن‌های باز تعهدی:
  $$\text{Liquidation Distance \%} = \frac{|\text{Mark Price} - \text{Liquidation Price}|}{\text{Mark Price}} \times 100$$
- **سطوح هشدار رنگی:**
  - 🟢 **ایمن (Safe):** فاصله بالای ۲۰٪
  - 🟡 **احتیاط (Caution):** فاصله بین ۱۰٪ تا ۲۰٪
  - 🔴 **خطر بالا (Danger):** فاصله کمتر از ۱۰٪ همراه با کارت و بج چشمک‌زن
- **سیستم هشدار صوتی آفلاین:** بوق هشدار ملایم با Web Audio API هنگام نزدیک شدن به مرز خطر (بدون نیاز به فایل‌های صوتی خارجی).

### ۶. 📋 مدیریت سفارشات باز نوبیتکس (Open Orders)
- **تب سفارشات باز زنده:** مشاهده، دسته‌بندی و فیلتر سفارش‌های باز اسپات و تعهدی به تفکیک بازار و جهت خرید/فروش.
- **لغو مستقیم سفارش از داخل داشبورد:** امکان لغو سفارش‌های لیمیت و استاپ با یک کلیک و به‌روزرسانی آنی رابط کاربری (نیازمند فعال بودن دسترسی معاملاتی کلید API).

### ۷. 🧮 ماشین‌حساب سایز پوزیشن و مدیریت ریسک
- **محاسبه ریاضی حجم مجاز ورود:** تعیین دقیق سایز پوزیشن بر مبنای سقف ریسک دلخواه (درصد از کل سرمایه یا مبلغ ثابت دلاری):
  $$\text{Position Size} = \frac{\text{Risk Amount}}{|\text{Entry Price} - \text{Stop Loss}|}$$
- **پیشنهاد اهرم بهینه:** محاسبه اهرم مناسبی که قیمت لیکوییدیشن را با فاصله امن در پشت حد ضرر قرار دهد.
- **هشدار بحرانی تلاقی لیکویید و حد ضرر:** نمایش اخطار قرمز در صورتی که با اهرم انتخابی، پوزیشن شما قبل از رسیدن به استاپ لاس لیکویید شود.
- **کپی ۱-کلیکه برنامه معامله:** فرمت‌بندی و کپی کلیه مشخصات ورود، استاپ، تارگت و حجم در کلیپ‌بورد با یک کلیک.

### ۸. 📝 ژورنال‌نویسی و ستون مقدار خالص خرید (Net Amount)
- **ستون مقدار خالص خرید (Net Amount):** محاسبه دقیق دارایی خالص اضافه‌شده به کیف پول پس از کسر کارمزد (`Amount - Fee`) در معاملات خرید و نمایش خط تیره در معاملات فروش.
- **تگ‌های استراتژی تکنیکال:** برچسب‌گذاری سریع (شکست مقاومت/حمایت، معامله روندی، پولبک، برخورد به سطوح، اسکالپ، خرید پله‌ای DCA) یا ساخت تگ‌های سفارشی.
- **پایش روانشناسی و کنترل هیجان:** ثبت وضعیت روانی (طبق استراتژی، ترس از جا ماندن FOMO، معامله انتقامی، معامله بر اساس خبر، خروج زودهنگام).

### ۹. 🖥️ طراحی بهینه برای مانیتورهای عریض (1920px Widescreen)
- **حداکثر عرض ۱۹۲۰ پیکسل:** بهره‌گیری حداکثری از فضای افقی نمایشگرهای بزرگ (2K، 4K و التراواید) بدون فشرده‌شدن ستون‌های پرتعداد جداول.
- **ایزولاسیون اعداد دوجهته (BiDi):** استفاده از کلاس `.bidi-num` و اجبار LTR در Canvas 2D به منظور جلوگیری از برعکس‌شدن علائم منفی/مثبت، علامت دلار و درصدها در حالت فارسی.

## 🚀 راهنمای نصب و اجرا

### پیش‌نیازها
- پایتون ۳.۱۲ یا بالاتر (`Python >= 3.12`)
- پکیج منیجر [uv](https://github.com/astral-sh/uv) (پیشنهادی و پرسرعت) یا `pip` استاندارد

### ۱. کلون و نصب پیش‌نیازها

```bash
git clone https://github.com/<your-username>/nob-api.git
cd nob-api
```

نصب پکیج‌ها با `uv`:
```bash
uv sync
```
*(یا با pip استاندارد: `pip install -e .`)*

### ۲. تنظیم اطلاعات دسترسی (API Key)

فایل نمونه متغیرهای محیطی را کپی کنید:
```bash
cp .env.example .env
```

فایل `.env` را باز کرده و کلیدهای دریافتی از صرافی نوبیتکس را در آن قرار دهید:
```env
# کلیدهای وب‌سرویس نوبیتکس (فقط خواندنی پیشنهاد می‌شود)
API=your_nobitex_api_key_here
SECRET=your_nobitex_secret_key_here
```

> 🔒 **توصیه مهم امنیتی:** هنگام ساخت API Key در پنل نوبیتکس، برای پایش صرف، دسترسی را روی حالت **«فقط خواندنی» (Read-Only)** قرار دهید. در صورتی که تمایل دارید سفارشات باز را از داخل داشبورد لغو کنید، دسترسی ثبت معامله (Trade) را فعال نمایید.

### ۳. اجرای داشبورد

اجرای وب‌سرور روی پورت **۸۰۸۰**:
```bash
uv run uvicorn nob.server:app --host 127.0.0.1 --port 8080 --reload --app-dir src
```

یا با استفاده از دستور کنسول نصب شده:
```bash
uv run nob-web
```

اکنون مرورگر خود را باز کرده و به آدرس زیر مراجعه کنید:
```
http://127.0.0.1:8080
```

## 🔒 امنیت و حریم خصوصی

- **ذخیره‌سازی کاملاً محلی:** کلیه سفارش‌ها، معاملات، تاریخچه سود و زیان و یادداشت‌های ژورنال صرفاً در پایگاه داده SQLite سیستم شما (`data/portfolio.db`) ذخیره می‌شوند.
- **ایمنی در برابر گیت (.gitignore):** تنظیمات فایل `.gitignore` مانع از آپلود شدن ناخواسته فایل‌های حاوی اطلاعات شخصی مانند `.env`، دیتابیس `portfolio.db` و لاگ‌ها به گیتهاب می‌شود.
- **عدم استفاده از CDNهای عمومی و ابزارهای رهگیری:** هیچ اسکریپت ردیابی یا اتصال خارجی در پروژه وجود ندارد. کلیه کتابخانه‌ها و فونت‌ها به صورت محلی در سورس پروژه ذخیره شده‌اند.
